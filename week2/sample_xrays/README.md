# Sample X-rays

All images are from the CC0 dataset
[Teeth Segmentation on dental X-ray images](https://www.kaggle.com/datasets/humansintheloop/teeth-segmentation-on-dental-x-ray-images)
by Humans in the Loop (`Teeth Segmentation JSON/d2/img/`). The number in each
file name is the original image number.

| File | Why it's here |
| --- | --- |
| `kaggle_dental_xray_1.jpg` | first image in the dataset |
| `kaggle_dental_xray_10.jpg` | isolated lower incisors/canines with visible bone loss — easiest to demo |
| `kaggle_dental_xray_26.jpg` | near-full adult dentition with clear roots — mostly healthy, good for Stage I teeth |
| `kaggle_dental_xray_42.jpg` | isolated lower teeth with clear roots and bone loss |

The full 5.3 GB dataset is not included.
