# Sample X-rays

All images are from the CC0 dataset
[Teeth Segmentation on dental X-ray images](https://www.kaggle.com/datasets/humansintheloop/teeth-segmentation-on-dental-x-ray-images)
by Humans in the Loop (`Teeth Segmentation JSON/d2/img/`). The number in each
file name is the original image number.

| File | Why it's here |
| --- | --- |
| `kaggle_dental_xray_1.jpg` | first image in the dataset |
| `kaggle_dental_xray_10.jpg` | mixed dentition with several isolated teeth and visible roots |
| `kaggle_dental_xray_26.jpg` | near-full adult dentition with multiple clear roots |
| `kaggle_dental_xray_42.jpg` | several isolated teeth with visible roots and bone loss |

The full dataset is not included.

These are panoramic radiographs and are included for workflow demonstration.
Panoramic blur, overlap, and geometric distortion can limit point-placement
precision; they should not be treated as a substitute for confirmatory
intraoral/periapical imaging or as a clinically validated reference set.
